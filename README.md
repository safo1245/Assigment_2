# Assigment_2

Question 1 — One-Dimensional Array

Description

In Question 1, a one-dimensional array is created and initialized with the following values:

5, -7, 12, 10, -7, 11, -6, 12, 1, -7, 2, 9

The program performs several operations on the array, including displaying its elements, calculating totals, and finding minimum and maximum values.

Tasks Completed

1. Declared and initialized the array.
2. Printed all array elements.
3. Calculated the total of all elements.
4. Calculated the total of even elements.
5. Calculated the total of odd elements.
6. Found the minimum element and its positions.
7. Found the maximum element and its positions.

Results

Total of all elements: 35
Total of even elements: 23
Total of odd elements: 12
Minimum element: -7
Minimum positions: 1, 4, 9
Maximum element: 12
Maximum positions: 2, 7

Note: PHP array positions start from index 0.
